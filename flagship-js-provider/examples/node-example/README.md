# Node.js Example - Flagship JS Provider

Interactive CLI example for testing the Flagship JS Provider in Node.js environment.

## Setup

```bash
npm install
```

## Run

```bash
npm start
```

**Note:** This example uses the SDK source files directly (no build needed). It uses `tsx` to run TypeScript files directly.

## Features

- Interactive menu for testing different flag types
- Test boolean, string, number, and object flags
- Test multiply function
- Set and view context
- Test all flags at once

## Usage

1. Run `npm start`
2. Choose an option from the menu (1-9)
3. View results in the terminal
4. Continue testing or exit
